## 2. CONTENT OPTIMIZATION CHECKLIST

### 2.1 On-Page SEO Checklist (Per Page)

```
□ Title Tag (50-60 chars)
  - Include primary keyword near front
  - Include brand name at end: " | Joy of Care"
  - Unique per page
  
□ Meta Description (150-160 chars)
  - Include primary keyword naturally
  - Include CTA: "Hubungi WhatsApp 08811-118-911"
  - Unique per page
  
□ H1 Tag (One per page)
  - Include primary keyword
  - Clear, descriptive heading
  - Matches search intent
  
□ H2-H3 Structure
  - Include secondary keywords
  - Logical hierarchy
  - FAQ sections with question keywords
  
□ Content Length
  - Homepage: 800-1,200 words
  - Service pages: 1,000-1,500 words
  - Blog posts: 1,500-2,500 words
  
□ Internal Linking
  - Link to related services (2-3 per page)
  - Link to relevant blog posts (1-2 per page)
  - Link to FAQ section
  - Use descriptive anchor text
  
□ Image Optimization
  - Alt text with keywords (descriptive, not spammy)
  - Compressed WebP format
  - Lazy loading enabled
  - File names: keyword-descriptive.webp
  
□ Schema Markup
  - MedicalBusiness (homepage)
  - MedicalService (service pages)
  - FAQPage (FAQ sections)
  - Article (blog posts)
  - BreadcrumbList (all pages)
  - Author (blog posts)
  
□ E-E-A-T Signals
  - Author bio with credentials
  - "Last updated" timestamp
  - Source citations for medical claims
  - Trust badges (Dinkes license, certifications)
```

## 3. GEO STRATEGY (AI Search Optimization)

### 3.1 How AI Search Engines Work

| AI Engine | How It Finds Content | Citation Factors |
|-----------|---------------------|------------------|
| **Google AI Overviews** | Google Search index + AI synthesis | E-E-A-T, schema, freshness, authority |
| **ChatGPT (GPTBot)** | Web crawling + Bing index | Structured content, citations, llms.txt |
| **Perplexity AI** | Bing + web crawling | Reddit mentions, citations, freshness |
| **Claude** | Web crawling | Clean HTML, structured data, citations |
| **Copilot** | Bing index | Microsoft ecosystem signals |

### 3.2 GEO Implementation Strategy

#### A. Technical Foundation (Week 1)

1. **llms.txt File** — Deploy to `/llms.txt`
   - Include: About, Services, Key Facts, Contact, Social
   - Keep under 500 words
   - Update monthly

2. **robots.txt AI Crawler Directives**
   ```
   User-agent: GPTBot
   Allow: /
   
   User-agent: OAI-SearchBot
   Allow: /
   
   User-agent: ClaudeBot
   Allow: /
   
   User-agent: PerplexityBot
   Allow: /
   
   User-agent: CCBot
   Disallow: /
   ```

3. **Structured Data (JSON-LD)**
   - MedicalBusiness on homepage
   - MedicalService on service pages
   - FAQPage on FAQ sections
   - Article on blog posts
   - BreadcrumbList on all pages
   - Author on blog posts

#### B. Content Structure for AI (Ongoing)

1. **Citation-Ready Passages**
   - Write 40-60 word paragraphs that answer specific questions
   - Include statistics and data points
   - Use clear, factual statements
   - Avoid hedging language

   Example:
   > "Joy of Care melayani panggil dokter ke rumah untuk area Jakarta, Tangerang, Depok, dan Bogor. Biaya all-in mulai dari Rp 380.000 sudah termasuk transport dokter. Tersedia 7 hari seminggu, jam 08:00-21:00. WhatsApp: 08811-118-911."

2. **FAQ Sections**
   - Add to every service page
   - Use question keywords from research
   - Include FAQPage schema
   - Target 5-7 FAQs per page

3. **Original Data Points**
   - Create surveys (100+ respondents)
   - Publish case studies
   - Share internal statistics
   - Create infographics with data

#### C. Off-Page AI Signals (Week 2-4)

1. **Brand Mentions**
   - Reddit: Answer health questions on r/indonesia
   - Quora: Answer homecare questions
   - Health forums: Participate in discussions

2. **Citation Building**
   - List on Halodoc, Alodokter, KlikDokter
   - Register on Google Business Profile
   - Submit to health directories

3. **Content Syndication**
   - Republish blog posts on LinkedIn
   - Share on Medium (with canonical)
   - Contribute to health publications

### 4.2 ChatGPT/Perplexity Optimization

#### A. Content Structure for AI Citations

1. **Paragraph Format**
   - 40-60 words per paragraph
   - First sentence: Direct answer to question
   - Supporting details: Statistics, facts, examples
   - Citation-ready: Include source attribution

2. **List Format**
   - Use numbered lists for processes
   - Use bullet lists for features/benefits
   - Include 3-7 items per list
   - Add context to each item

3. **Table Format**
   - Use for comparisons
   - Include headers
   - Keep cells concise
   - Add context above/below

#### B. Content Types for AI Citations

1. **Definitional Content**
   - "What is [service]?" pages
   - Clear, concise definitions
   - Include statistics and data
   - Link to related content

2. **How-To Content**
   - Step-by-step guides
   - Include prerequisites
   - Add tips and warnings
   - Link to booking page

3. **Comparison Content**
   - "[Service A] vs [Service B]"
   - Pros and cons
   - Use cases
   - Pricing comparison

4. **FAQ Content**
   - Question-and-answer format
   - Include schema markup
   - Target long-tail questions
   - Update regularly
